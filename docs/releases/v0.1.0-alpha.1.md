# FCS-Scribe v0.1.0-alpha.1

Initial **experimental prerelease** of the FCS Extended change-documentation
plugin. This is not a production-ready or generally compatible FCS release.

## Included

- Explicit, immutable tracking baselines and deterministic comparisons of
  captured in-memory records, names, fields, references, and instances.
- Exact typed before/after evidence, stable IDs, available reference names,
  stored/effective layers, and explicit unresolved/partial-data warnings.
- Manual versioned JSON AI packets, editable draft import/paste, evidence
  validation, stale-draft checks, duplicate-batch detection, and approval.
- Append-only use of FCS's per-record Notes/TODO facility, preserving active
  and inherited text/categories, marking the editor dirty, and leaving Save
  to the user.
- Installation/build instructions, a complete feature/acceptance plan, and a
  wiki covering architecture, coding decisions, references, and knowledge credits.

## Requirements and installation

Windows, .NET Framework 4.8, installed FCS Extended, and the inspected Steam
FCS 2.14.2 executable are required. The executable is checked against SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

With FCS closed, extract the archive and copy its `FCS-Scribe` directory to
`<Kenshi>\mods\FCS-Scribe`. Launch FCS Extended, enable the extension, and open
a writable `.mod`. Start with disposable copies and back up FCS notes files.
The archive does not include Kenshi, FCS, or FCS Extended binaries.

## Important limitations

Notes are editor-side per-record annotations in `data\__TODO__<user>.txt`,
**not embedded in the `.mod`** and not Steam Workshop change notes.
Extraction is partial; pending controls, external files, mod metadata, and
separate dialogue buffers are not comprehensively tracked. Baselines live only
for the current plugin window/session. Multi-record application is not
transactional, and the plugin never silently saves.

The real FCS Extended startup/toolbar/dialog workflow still needs a manual
acceptance pass. Automated checks exercised actual FCS forms and normal
save/reopen methods on disposable copies, not the complete interactive loader.
Other FCS builds, including GOG, have not been validated.

OpenConstructionSet integration, persistent history, Markdown exports,
dependency-resolved wiki data, and direct AI-provider connections are **planned,
not shipped**.

## Verification and source

The recorded checks cover the deterministic core and disposable vanilla/mod
save/reopen workflows. See the [feasibility report](https://github.com/Atlasroar/FCS-Scribe/blob/main/docs/feasibility.md)
and [working plan](https://github.com/Atlasroar/FCS-Scribe/blob/main/docs/plan.md)
for exact evidence and remaining gates.

The release archive includes `release.json` identifying its source commit.
The matching Git tag and GitHub source archives provide the corresponding
GPL-3.0 source. A separate `.sha256` asset verifies the plugin archive.

# FCS-Scribe v0.1.0-beta.1

Beta prerelease of the FCS Extended documentation plugin. This beta remains
**experimental**: it supports one inspected Steam FCS build, and the complete
interactive acceptance gate is still open.

## Changes since v0.1.0-alpha.1

- Capture the Workshop title, author, version, description, required and
  referenced mods, tags, staged change notes, Steam ID, cached last update,
  visibility, and local preview details.
- Add a read-only Workshop tab and standalone **Export Workshop info** JSON
  export, with no baseline or gameplay changes required.
- Include Workshop context in **schema-2 AI packets**, without inventing
  gameplay change evidence. Schema-1 packets remain readable. Metadata changes
  after export invalidate stale drafts.
- Identify local/staged/cache sources explicitly. Missing values remain
  unknown; Steam IDs are strings, and unpublished/default IDs and unknown
  visibility codes are distinguished from missing data.
- Add **Archive preview image** for byte-identical PNG/JPEG/GIF copies with
  original encoding, byte count and SHA-256. Require a new destination outside
  Kenshi; preserve the source and reject existing targets, changed previews,
  unsupported formats and images larger than FCS's 1 MB limit.
- Embed Scribe as a native FCS MDI child window.
- Show explanations for all eight action buttons at the bottom on hover or
  keyboard focus, without erasing the last operation's status.
- Expand the feature plan, architecture/contract documentation, and disposable
  checks for the new metadata, archive and UI behavior.

Workshop capture does not query Steam, invoke Refresh/Upload, or save the mod.
Capture is blocked while an existing Workshop upload or connected refresh is
in progress, without preventing offline capture.

## Installation and upgrade

Requirements: Windows, .NET Framework 4.8, installed FCS Extended, and the
inspected Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Close FCS, extract the archive, and copy its `FCS-Scribe` folder into
`<Kenshi>\mods\FCS-Scribe`, replacing the older plugin files if upgrading.
Launch FCS Extended and enable FCS-Scribe. Start with disposable mod copies
and back up your FCS notes files. No live installation is changed by building
or downloading this release.

Open the active mod's **Steam Workshop** window before capturing staged
title/tags/visibility or its change-notes draft. Without a matching dialog,
Scribe can read the active header and any saved local cache, but staged notes
are unknown. Archive the preview separately from its JSON metadata.

## Important limitations

- Workshop information is local/staged/cached, not verified current published
  Steam state. The change-notes field is an upload draft, not published history.
- Record Notes/TODO entries remain editor-side `data\__TODO__<user>.txt`
  annotations, not `.mod` content or Workshop change notes. Applying approved
  notes marks FCS dirty but does not save.
- Extraction is partial. General external files, metadata change history,
  layouts, separate dialogue buffers and pending controls are not
  comprehensively tracked.
- Baselines are session-only. Notes application is not transactional.
- Real FCS Extended loader/dialog behavior, embedded resize/minimize/restore
  and real Workshop/archive interactions still need manual acceptance.
- Other FCS builds, including GOG, remain unvalidated. OCS integration,
  persistent history, Markdown/wiki-ready gameplay exports and direct AI
  connections are planned, not shipped.

## Validation and source

Recorded checks: **47 core**, **88 disposable vanilla FCS**, and **87
representative-mod FCS** checks passed. The representative mod has no instances;
that mutation was explicitly skipped there and covered by vanilla. These checks
do not replace the interactive acceptance gate.

See the [feasibility report](https://github.com/Atlasroar/FCS-Scribe/blob/main/docs/feasibility.md)
and [working plan](https://github.com/Atlasroar/FCS-Scribe/blob/main/docs/plan.md)
for evidence and remaining work.

The ZIP includes this project's plugin, manifest, documentation, GPL-3.0
license, and `release.json` source-commit metadata. No Kenshi, FCS or upstream
FCS Extended binaries are bundled. The separate `.sha256` asset verifies the
ZIP; the matching Git tag/source archives supply corresponding source.

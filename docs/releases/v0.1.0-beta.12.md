# FCS-Scribe v0.1.0-beta.12

Experimental beta addressing **S10: tracking is not mod recovery**. S09 remains
open with its recorded physical acceptance results and explicit untested
boundaries; S11-S16 remain separate work.

## Changes since v0.1.0-beta.11

- Keep a wrapping tracking-boundary notice visible independently of transient
  operation status and action help. Captured state can include **unsaved**
  edits; saved `.mod`/Notes state is **not verified** by tracking.
- Clarify New versus Resume, display last-recorded UTC rather than implying
  normal FCS Save, and explain that interrupted-log repair and legacy
  conversion never restore or save gameplay/notes.
- Explain discrepancy decisions: No declines this tracking session; Yes keeps
  the current editor. The next manual or eligible automatic Review records
  differences, including reversals of discarded edits, as new observations.
- Document a private backup workflow separating the actual mod folder, native
  shared Notes/TODO files, complete tracking storage, workspaces and settings.
  Include the security policy in the release archive so its README link works.
- Add an isolated `-RecoveryOnly` integration suite using actual FCS model,
  save/reload and asynchronous window paths on disposable copies.

No tracking, journal, packet, workspace or settings schema migration. No mod
restoration tool, binary writer, automatic Save or history rewrite is added.

## Installation and compatibility

Requirements: Windows, .NET Framework 4.8, installed FCS Extended and the
inspected Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Back up the actual mod and relevant native notes files first. Close FCS, extract
the archive and copy its `FCS-Scribe` folder into `<Kenshi>\mods\FCS-Scribe`,
replacing older plugin files. Launch FCS Extended and enable FCS-Scribe.
Building/downloading does not install or modify the game. Existing projects
need no migration; retain their baseline and complete matching `.scribe` folder.

## Validation and boundaries

Recorded checks: **593 core**, the plugin build, and **94 recovery-boundary
checks each on vanilla and representative disposable copies** passed. The
targeted suite includes persistent UI/help/wrapping, an unsaved rename followed
by native saved-model reload, Resume No/Yes, byte-preserving rejection, new
reversal evidence, compiled/uncompiled history, explicitly saved edits ahead
of tracking, native notes persistence and complete byte-identical backup/replay.

Resume decisions are injected at the window boundary, not clicked through
every native dialog. A fresh native model reload simulates the state after
discarding unsaved edits; no physical process/power failure is forced. The
live installation, original test mod and shared notes are not modified.
Arbitrary backup restoration/relocation, broader stacks and complete FCS
Extended interaction are not newly claimed.

The ZIP includes this project's plugin, manifest, README, security policy,
documentation, GPL-3.0 license and `release.json` identifying the exact source
commit. No Kenshi, FCS or upstream FCS Extended binaries are bundled. Verify
the ZIP against its `.sha256` asset; the matching Git tag/source archives
supply corresponding source.

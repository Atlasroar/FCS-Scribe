# FCS-Scribe v0.1.0-beta.13

Experimental beta addressing **S11: partial capture and interval sampling**.
S09 remains open with its recorded physical acceptance and untested boundaries;
S12-S16 remain separate work.

## Changes since v0.1.0-beta.12

- Always show partial-extraction warnings after creating a baseline, not just
  when optional Workshop capture is partial.
- Keep shared sampling guidance in reviews (including zero evidence), range
  previews and restored-packet display. Recordings observe committed model
  state, not editor events; A-to-B-to-A edits between recordings can be missed.
- Add the guidance to new packet instructions without changing snapshot
  warnings, fingerprint formats, schemas or original historical/nested packets.
- Publish a supported/omitted-state matrix covering pending controls, dialogue
  buffers, external files, layered provenance and saved-state/event-log limits.
- Add an isolated `-SamplingOnly` suite for the real bound native Name textbox,
  its pending/commit/cancel/focus boundaries and sampled/unsampled reversals.

No forced control flush, automatic Save, binary writer or history rewrite is
added. "Committed" means a control updated the in-memory model, not a saved mod.

## Installation and compatibility

Requirements: Windows, .NET Framework 4.8, installed FCS Extended and the
inspected Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Back up the actual mod and relevant native notes files first. Close FCS, extract
the archive and copy its `FCS-Scribe` folder into `<Kenshi>\mods\FCS-Scribe`,
replacing older plugin files. Launch FCS Extended and enable FCS-Scribe.
Building/downloading does not install or modify the game. Existing projects
need no migration; retain their baseline and complete matching `.scribe` folder.

## Validation and boundaries

Recorded checks: **598 core**, the plugin build, **22 sampling-boundary checks
each on vanilla and representative disposable copies**, and **94 existing
representative recovery-boundary checks** passed.

The real bound Name textbox receives programmatically raised, wired WinForms
Enter/Escape events and an actual LostFocus transition. Pending text is omitted
until native commit; Review does not flush it. Separately recorded forward and
reverse edits remain observations; reversals between reviews can vanish from
evidence. Mod bytes, notes, dirty state, session hashes and original packets
are checked. No live installation or original mod/notes files are modified.

This is not physical keyboard input through full FCS Extended, complete control
coverage or saved-state verification. Numeric/dropdown/reference/dialogue
controls, separate buffers, arbitrary external assets and full interactive
acceptance are not newly claimed.

The ZIP includes this project's plugin, manifest, README, security policy,
documentation, GPL-3.0 license and `release.json` identifying the exact source
commit. No Kenshi, FCS or upstream FCS Extended binaries are bundled. Verify
the ZIP against its `.sha256` asset; the matching Git tag/source archives
supply corresponding source.

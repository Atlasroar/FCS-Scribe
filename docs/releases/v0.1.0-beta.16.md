# FCS-Scribe v0.1.0-beta.16

Experimental beta completing bounded **S13 storage/distribution safeguards**.
The owner accepted S12 for the documented tested configuration after beta 15's
two-hour actual-editor soak and cold Resume. Custom stacks and broader
headroom/latency remain unverified; S09 full acceptance and S14-S16 remain open.

## Changes since v0.1.0-beta.15

- Add shared persistent main-window and Start/Resume complete-set/privacy
  guidance naming the baseline, marker, journal, sessions and recovery/backups.
  Baselines contain full loaded/dependency data, not safe AI/upload material.
- Clarify that missing/incomplete modern storage requires the matching
  `.json.scribe` folder, including `project.json`.
- Document private closed-copy/restore, compiled-session archival and
  pre-Workshop content inspection, including missing/mixed-file recovery limits.
- Add disposable complete-set regressions for original evidence, hashes,
  pending replay, idempotent compilation, archival and exact-file restoration.
- Keep chooser buttons visible below both notices and wrap the persistent
  warning in narrow windows.

The active-mod-folder default is unchanged. No schema, identity, evidence,
fingerprint, hash/chain, flush or original-retention changes. No automatic
backup, pruning, archive wizard, mod relocation or journal merge.
**Scribe does not inspect, filter or block native Workshop uploads.**

## Verification and limits

639 core checks and the plugin build passed. Copied official-data and
representative-mod recovery runs each passed 98 checks, including notice
layout. Tracking tests preserve original closed sets and exercise:

- Complete copies replay compiled/pending entries with unchanged evidence.
- Closed fully compiled session archival retains journal history.
- Missing latest/middle pending sessions, marker/baseline and foreign
  marker/journal reject without changing remaining bytes.
- All intact originals can reconstruct a missing journal as pending history;
  missing journal plus required archived originals rejects instead.
- Restoring exact missing files permits replay; compilation does not duplicate.

These are tracking-storage checks, not complete mod/notes restoration or
physical disk/power-failure guarantees. Older compatible roots cannot prove
missing sidecars, and coherent old backups cannot prove newer history exists.
No live files were mutated and no Steam upload was performed. The previously
documented representative general-suite fixture limitation remains; no new
general-suite or full interactive acceptance is claimed.

## Installation and compatibility

Requires Windows, .NET Framework 4.8, installed FCS Extended and the inspected
Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Back up the actual mod, relevant Notes/TODO files and complete private tracking
set first. Close FCS, extract the archive and copy its `FCS-Scribe` folder into
`<Kenshi>\mods\FCS-Scribe`, replacing older plugin files. Launch FCS Extended
and enable FCS-Scribe. Existing projects need no migration or baseline rewrite.
Keep tracking data, backups and saved draft workspaces out of actual upload
content; confirm the native uploader's selected contents before publishing.

The archive contains this project's plugin, manifest, README, security policy,
documentation, GPL-3.0 license and exact-source `release.json`, not upstream
game/FCS binaries or test fixtures. Verify the ZIP with its matching `.sha256`
asset; the matching Git tag/source archives supply corresponding source.

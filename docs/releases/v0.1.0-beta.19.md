# FCS-Scribe v0.1.0-beta.19

Experimental beta recording bounded **S16 compatibility/provenance evidence**.
Runtime behavior and the single supported executable hash are unchanged.
S09 interactive acceptance and explicit MVP support-scope review remain open.

## Changes since v0.1.0-beta.18

- Document an exact build/configuration matrix separating disposable native
  hosts, managed interface evidence and full FCS Extended acceptance.
- Add `-CompatibilityOnly` for executable, editing/context and source-label
  guards, followed by existing Workshop provenance/isolation checks in a fresh
  process. The default combined checks also include the compatibility host.
- Allow `-VanillaStack` with compatibility checks as well as profiling, using
  copied `gamedata.base`, `Newwworld.mod`, `Dialogue.mod` and `rebirth.mod`.
- Keep literal unresolved base/locked ownership and local/staged/cached
  Workshop context explicit; recheck the designated authoritative upstream
  interface/loader and native game-library guidance at unchanged revisions.

No runtime guard, fingerprint, schema, note application, storage, default,
retention or consent change. No new dependencies, hooks, source inference,
automatic dependency resolution or live plugin installation.

## Verification and limits

664 core checks/build passed. Copied official data passed 23 compatibility
checks; the copied four-file vanilla stack plus a representative active mod
passed 26. Both include a controlled copied overlay loaded through native
LOCKED mode, not a third-party locked-mod acceptance test.

Guards reject a differing assembly before editor reflection, merge/non-mod
paths, replaced data sessions and changed reported loaded/locked context.
Inherited/locked changes cannot become active-mod evidence. Unchanged stacks
and explicit fresh locked-stack baselines remain no-ops; mod/overlay bytes and
dirty state remain unchanged. Context edits are controlled model mutations,
not real hot-unloading/reordering; the negative executable is the test host,
not another inspected FCS release.

Separate single-dependency official/representative Workshop hosts each passed
114 provenance/isolation checks. These cover cache versus staged/unknown/busy
values, dependency lists without header mutation, optional failures and
recovery; no Steam Refresh/Upload or published-state query occurs. They do
not load the four-file stack. Expected injected errors are logged.

Other hashes/builds, custom stacks, other extensions, physical failure modes,
full source ownership and complete FCS Extended startup/UI acceptance remain
unsupported or unverified. Earlier S09/soak evidence has its original scope,
not blanket beta 19 acceptance. No live mod files were changed.

## Installation and compatibility

Requires Windows, .NET Framework 4.8, installed FCS Extended and the inspected
Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Back up the actual mod, relevant shared `data\__TODO__<user>.txt` sidecars and
complete private tracking set first. Close FCS, extract the archive and replace
the `FCS-Scribe` folder in `<Kenshi>\mods\FCS-Scribe`. Launch FCS Extended and
enable FCS-Scribe. Preserve private workspaces separately; keep tracking,
backups and whole shared sidecars out of public upload content.

The archive contains this project's plugin, manifest, README, security policy,
documentation, GPL-3.0 license and exact-source `release.json`, not upstream
game/FCS binaries or test fixtures. Verify the ZIP with its matching `.sha256`
asset; the matching Git tag/source archives supply corresponding source.

# FCS-Scribe v0.1.0-beta.2

Experimental beta prerelease of the FCS Extended documentation plugin.
The full interactive FCS Extended acceptance gate remains open; use disposable
mod copies first.

## Changes since v0.1.0-beta.1

- Start a new tracking project or validate/resume an existing one in the
  background. Keep one full starting baseline instead of rewriting it on
  every review.
- Open a new UTC timestamp + unique-ID session log on every start/resume.
  Record only changed records/context since the last durable entry; unchanged
  state creates no duplicate entry.
- Flush each recording before advancing the comparison baseline. Reopening
  replays compiled and uncompiled entries, including context-only changes.
- Add Plugin settings with Manual (default), 30-second, 1-minute, 5-minute
  and 10-minute recording intervals.
- Automatically compile durable session entries into the main journal every
  30 minutes on a separate deadline. Add Compile journal for explicit
  compilation in manual mode. Compilation is idempotent and retains session
  originals.
- Pause automatic work while hidden, minimized, busy or blocked by visible
  modal forms. Errors pause scheduling; closing stops new work.
- Add project writer exclusion, durable-head markers, missing-history checks
  and explicit interrupted-tail recovery. Recovery preserves original bytes
  before removing an incomplete final line; complete corrupt entries are
  rejected rather than skipped.
- Warn before resuming when the editor differs from recorded state.
  Tracking does not restore lost or discarded mod edits.
- Preserve compatible older full-state tracking roots. Legacy schema-1/2 AI
  packets require approved conversion: retain exact bytes in `.legacy.bak`
  and evidence as history, then establish a fresh current-editor baseline.
- Default JSON dialogs to the active mod's actual directory, with persisted
  custom defaults and per-dialog overrides. Existing tracking files do not
  move when settings change.
- Expand the feature list, operating instructions, plan, contracts and
  disposable-copy coverage. All ten actions have bottom hover/focus help.

The existing Workshop metadata, preview-image archive, embedded MDI window and
human-approved Notes/TODO workflow remain available. No automatic recording or
compilation saves a `.mod`, applies AI notes or sends network requests.

## Installation and upgrade

Requirements: Windows, .NET Framework 4.8, installed FCS Extended and the
inspected Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Close FCS, extract the archive, and copy its `FCS-Scribe` folder into
`<Kenshi>\mods\FCS-Scribe`, replacing the older plugin files if upgrading.
Launch FCS Extended and enable FCS-Scribe. Back up your mod projects and FCS
notes files before trying this experimental build. Building or downloading
the release does not install it or modify your game.

Use Start tracking to choose a project JSON. Keep that JSON together with its
adjacent `<file>.json.scribe` storage: `project.json`, `journal.jsonl` and
uncompiled `sessions` logs. Back up the entire project. Session originals are
never automatically deleted; close Scribe before manually archiving fully
compiled sessions.

## Important limitations

- Tracking is not a `.mod` backup or automatic lost-edit recovery.
- The full baseline includes loaded dependency records, and session logs can
  contain private data. Do not send tracking storage/backups to AI or include
  them in Workshop uploads. Use compact Export AI packet for sharing.
- Interval sampling misses changes reverted between ticks. Extraction remains
  partial: pending controls, dialogue buffers and general external files are
  not comprehensively tracked.
- Large loaded models can still pause the UI or pressure 32-bit memory.
  Unpruned history increases replay/validation costs.
- There is no history-management UI or combined multi-batch AI export yet.
  AI export uses pending evidence or the latest compatible saved batch.
  Editable drafts/export associations remain window-local.
- Writer leases coordinate Scribe instances, not arbitrary external editors.
  Hashes are self-consistency checks, not signatures. Older roots without a
  journal-version marker cannot themselves detect missing sidecars.
- Workshop information remains local/staged/cached, not verified current
  Steam state. Notes/TODO annotations remain editor-side, not `.mod` content;
  applying notes is not transactional and never saves automatically.
- Full FCS Extended loader/dialog, long-running close/recovery, real scheduling
  and broader mod-stack acceptance remain pending. GOG and other executable
  builds remain unvalidated.
- OCS integration, Markdown/wiki-ready gameplay exports and direct AI-provider
  connections are planned, not shipped.

## Validation and source

Recorded checks: **138 core**, **116 disposable vanilla FCS**, and **115
representative-mod FCS** checks passed. The representative mod has no instances;
that mutation was explicitly skipped there and covered by vanilla.
Automated checks do not replace interactive acceptance.

The ZIP includes the plugin, manifest, README, documentation, GPL-3.0 license
and `release.json` with the exact source commit. No Kenshi, FCS or upstream
FCS Extended binaries are bundled. Verify the ZIP against its separate
`.sha256` asset; the matching Git tag/source archives supply corresponding
source.

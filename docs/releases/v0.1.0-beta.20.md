# FCS-Scribe v0.1.0-beta.20

Experimental beta adding explicitly requested **Scribe-owned notes and mod
tasks**. Native FCS annotations remain separate. S09 interactive acceptance
and explicit MVP support-scope review remain open.

## Changes since v0.1.0-beta.19

- Independently opt into plain free-form `notes.txt` and record-linked
  `todo.txt` in Settings. Write in Notes; edit/remove/check tasks in Mod To Do.
- Add **Add Mod To Do** immediately below native **Add Todo Item** in the main
  Game World record-list context menu, without replacing the native action.
  Selected records retain their IDs/names in Scribe's separate readable file.
- Save enabled work on Scribe actions, eligible automatic recording and normal
  close. **Core > Save Changes** replaces Review changes; it also works for
  enabled Scribe text without tracking. It does **not** save `.mod`, native
  Notes/TODO or the editable AI draft workspace.
- Put **Save workspace / Open workspace** in their own **Workspace** dropdown;
  Draft retains Import/Paste.
- Default project settings/text/new destinations to the active mod folder.
  An optional external project directory is discovered through a small
  mod-local `FCS-Scribe.location.json`. Existing tracking/workspaces/text are
  not moved; each root retains its own files. The separate export override
  remains available.
- Use same-stream hashes, strict UTF-8, atomic text replacement, cooperating
  leases and unique original-byte backups. Stale/conflicting writes fail
  visibly and retain local/external intent. Recovery disables task mutations.
  Settings and locator destinations also protect recognized tracking storage.

## Settings and recovery notice

Settings now use `<project folder>\FCS-Scribe.settings.json`, bound to the mod
path. Old `%LOCALAPPDATA%\FCS-Scribe\settings.json` is retained, **not silently
imported**. Missing mod-local settings start Manual with both text features off.
Configure each mod explicitly. Disabling a feature does not remove its file.

An unrelated/malformed `todo.txt` is not overwritten: preserve it and choose a
separate project folder, repair the documented format or disable Mod To Do.
Existing UTF-8 `notes.txt` is plain writing. The two text files save independently;
a notes save can succeed before a later TODO conflict. External root switching
is not transactional: failed pointer writes can leave candidate settings while
the window stays bound to its old root. Preserve both roots and retry after
resolving the reported failure.

Copy unsaved editor text before explicit Reload/discard. Unique `.backup-<ID>`
text originals and settings recovery backups are not public mod content.
Keep settings/locators, full tracking data, workspaces and backups out of uploads.
Review notes/tasks before intentionally distributing them with a mod.

## Verification and limits

694 core checks and the plugin build passed. Copied official-data and
representative-mod native hosts each passed 95 mod work/menu checks, including
actual multi-selection, root-switch failure/retry, conflict retention,
manual/automatic/close persistence and unchanged native mod/notes/dirty state.
Targeted regressions: 16 settings, 24 scheduling, 24 export protection,
116 tracking recovery and 36 native notes safety + 8 cold-process reopen.
The synthetic profiling compiler dependency smoke check passed.

These are disposable native-host checks, not complete FCS Extended startup or
physical interactive acceptance. The menu extension covers the main record
list, not every properties menu. No physical power/disk-failure guarantee,
data migration, native notes-button hijack or vanilla-to-text export is added.
No live installation/original data changes, new dependencies or native hooks.

## Installation and compatibility

Requires Windows, .NET Framework 4.8, installed FCS Extended and the inspected
Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Back up the actual mod, relevant shared `data\__TODO__<user>.txt` sidecars,
Scribe text/settings, complete private tracking set and draft workspaces first.
Close FCS, extract the archive and replace the `FCS-Scribe` folder in
`<Kenshi>\mods\FCS-Scribe`. Launch FCS Extended and enable FCS-Scribe.
Configure this mod's settings explicitly as described above.

The archive contains this project's plugin, manifest, README, security policy,
documentation, GPL-3.0 license and exact-source `release.json`, not upstream
game/FCS binaries or test fixtures. Verify the ZIP with its matching `.sha256`
asset; the matching Git tag/source archives supply corresponding source.

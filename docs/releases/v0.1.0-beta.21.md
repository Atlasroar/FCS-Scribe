# FCS-Scribe v0.1.0-beta.21

Experimental beta implementing the requested warning/help layout cleanup.
Existing tracking, storage guards, explicit approval and native-save boundaries
are unchanged. Full interactive acceptance remains open.

## Changes since v0.1.0-beta.20

- Replace separate top warning labels with one read-only, wrapping, vertically
  scrollable bottom information box.
- Show tracking/privacy information and applicable settings-recovery and
  pending-compilation notices by default. Menu hover or keyboard selection
  temporarily shows the action's help in that same box.
- Restore current information when leaving an action/menu, closing a dropdown
  or overflow menu, switching tabs or beginning an operation. Selected-item
  repainting does not resurrect stale help after menu dismissal.
- Keep plugin activity, results and errors in their own status area.
- Retain Notes and Mod To Do's existing settings-aware messages in their tabs;
  do not duplicate their enable/disable instructions in the bottom box.
- Keep recovery and compilation state current behind transient help. Legacy
  settings-location guidance cannot replace an actual settings-recovery error.

This intentionally replaces always-visible warning labels with default
information that yields to contextual help. The Start/Resume chooser retains
its explicit tracking and private-storage warnings.

## Verification and limits

694 core checks and a warnings-as-errors plugin build passed. Targeted
disposable native-host checks passed: 104 mod-work/menu, 20 settings recovery
and 25 compilation scheduling. These cover mouse/keyboard/overflow help,
restoration and stale-help prevention, narrow-window scrolling, settings and
compilation transitions, separate errors and tab-local settings guidance.

These are copied-input native-form checks, not complete physical FCS Extended
startup or interactive acceptance. No live installation, original game/mod
data, native hooks, new dependencies or storage-format changes were introduced.
The existing S09 and explicit MVP support-scope review remain open.

## Installation and compatibility

Requires Windows, .NET Framework 4.8, installed FCS Extended and the inspected
Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Back up the actual mod, native annotations, Scribe text/settings, complete
private tracking set and AI draft workspaces. Close FCS, extract the archive
and replace the `FCS-Scribe` folder in `<Kenshi>\mods\FCS-Scribe`. Launch FCS
Extended normally and enable FCS-Scribe. Existing settings and text files
do not need migration.

Verify the ZIP against its matching `.sha256` asset. The archive contains this
project's plugin, documentation and license, with exact-source `release.json`;
it does not include upstream binaries or test fixtures. The matching Git tag
and source archives provide corresponding source.

# FCS-Scribe v0.1.0-beta.22

Experimental beta adding the owner-selected Markdown changelog export.
No OCS, provider connection, new runtime or native save behavior is introduced.

## Changes since v0.1.0-beta.21

- **Core > Export Markdown** selects/previews an inclusive recording range and
  exports readable captured facts without an AI draft.
- **Draft > Export reviewed Markdown** exports the associated original
  catalogue and complete, current-state-valid draft prose in separate sections,
  with citations linking to factual evidence rows. Restored workspaces need no
  open tracking project.
- Preserve exact typed values, source/layer labels, unresolved references,
  qualified evidence IDs, original recordings and current/historical warnings.
  Group stored/effective views without dropping evidence or treating them as
  independent gameplay edits; retain reversals and unrecorded-state labels.
- Escape untrusted text, HTML/Markdown and literal URLs. Identical packet/draft
  input produces identical UTF-8/LF output; no second diff engine is added.
- Guard `.md` locations and observed bytes. Only intact generated documents
  may be replaced; edited, unrelated, damaged or tracking/reserved targets are
  refused. Markdown shares JSON's flushed, hash-checked atomic commit primitive.
- Leave the editable draft, original packet, workspace and tracking history
  intact. Recheck live state and reviewed-draft revisions before writing.
  Neither export queries/applies native annotations or records/compiles/saves
  the mod. Enabled Scribe notes/tasks still save on ordinary Scribe actions.

The first-line format marker includes a body SHA-256 for consistency and safe
replacement recognition, not authorship/signing. Keep original JSON evidence
and workspaces; Markdown cannot resume tracking or restore an editable draft.

## Installation and compatibility

Requires Windows, .NET Framework 4.8, installed FCS Extended and the inspected
Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Back up the mod, native shared annotations, Scribe text/settings, complete
private tracking set and AI draft workspaces. Close FCS and install the
`FCS-Scribe` folder from the verified ZIP normally; do not replace upstream
binaries. Existing JSON/text storage does not need migration.

Verify the archive against its matching `.sha256` asset. `release.json` records
the exact source commit and guarded executable hash. The archive contains this
project's plugin, documentation and license, not upstream binaries or fixtures.

# FCS-Scribe v0.1.0-beta.23

Experimental beta adding the owner-selected read-only recording-history browser.
No OCS, new runtime, history pruning or native save behavior is introduced.

## Changes since v0.1.0-beta.22

- **Core > Browse history** reads the same validated, detached catalogue used
  by existing AI/Markdown range exports.
- Browse sessions or search stable IDs, names, fields, typed values, source
  labels and historical/context/Workshop warnings.
- Inspect exact original changes, batch/baseline/fingerprint identities,
  qualified citations and loaded/locked/dependency context.
- Keep compiled/uncompiled observations in verified order, with no duplicate
  evidence. Legacy checkpoints/imports, context-only updates and current
  **UNRECORDED** edits remain explicit; empty sessions invent no recordings.
- Select entries with Ctrl/Shift, then choose **Export AI range...** or
  **Export Markdown range...**. The shared inclusive range preview retains all
  intervening entries, even filtered-out/unselected ones.
- Opening, filtering or closing the browser saves nothing, including enabled
  unsaved Scribe notes/tasks. Explicit exports keep normal Scribe text saves
  and existing destination/current-state checks.
- AI keeps draft save/discard protection; Markdown facts retain the existing
  draft/workspace association. No recording, compilation, native annotations,
  mod save/restoration, JSON migration or second diff engine is added.

The browser is a detached snapshot; close/reopen to refresh. It is not a saved
mod view, net diff, event log, applied-notes ledger or retention editor.

## Verification and limits

769 core checks and a warnings-as-errors plugin build passed, plus 65 targeted
copied-native export/history and 113 menu/mod-work checks on a small existing
single-record disposable fixture. They cover identities/filters/warnings,
empty/legacy/pending/context-only states, inclusive range selection and
cancellation, existing writer reuse and unchanged native/tracking/draft state.

The reported owner-handle failure was reproduced in the copied model-only
test setup. Constructing/showing the Scribe owner in its standard MDI host
before modal actions fixed that fixture; the actual Core action now passes.
No production error suppression or owner fallback was added.

These checks do not establish new physical FCS Extended acceptance, broader
executable/stack support or physical storage-failure guarantees. The beta 21
owner checklist and unresolved saved-mod byte change remain documented.
No live installation or original mod/native-sidecar repair was performed.

## Installation and compatibility

Requires Windows, .NET Framework 4.8, installed FCS Extended and the inspected
Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Back up the mod, native shared annotations, Scribe text/settings, complete
private tracking set and AI draft workspaces. Close FCS, verify the ZIP against
its matching `.sha256` asset and install its `FCS-Scribe` folder normally.
No existing storage migration is required; do not replace upstream binaries.
`release.json` binds the archive to its source commit and guarded executable.

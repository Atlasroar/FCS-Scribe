# FCS-Scribe v0.1.0-beta.24

Experimental beta adding task search, filters and a sortable table entirely
inside Scribe's opt-in **Mod To Do** tab. FCS's native TODO window is unchanged.

## Changes since v0.1.0-beta.23

- Replace the simple Scribe task list with **Done, Item name, String ID, Item
  type, Priority, Created date and Description** columns.
- Search all fields or one selected field; combine **All / Open / Completed**,
  item type, priority and inclusive local-calendar From/To date filters.
- Sort by clicking column headings; click again to reverse. Clear filters
  restores the full task catalogue. Queries never save work or reorder tasks
  in the file, and edits target stable task identities after filtering/sorting.
- Edit priority directly (**Low / Normal / High**, or **Unspecified**). Retain
  Done checkboxes and the existing full-text description editor.
- New tasks capture the linked record type and UTC task-creation time and
  default to Normal priority. Names/types are captured labels, not live record
  updates; creation dates describe Scribe tasks, not FCS records.
- Hide the entire task table/search/filter/action workspace when Mod To Do is
  off, keeping the tab's enablement explanation. Recovery disables mutation and
  reports errors; ordinary save/conflict/backup guards remain.

No OCS, additional runtime, native annotations, mod save, gameplay tracking
schema migration or AI handoff changes are introduced. Plain notes remain a
separate file and editor.

## Task-file upgrade and downgrade

Existing format-1 `todo.txt` files load without rewriting, including unchanged
Save Changes. Their type/date remain Unknown and priority Unspecified; no
historical metadata is invented. Date filters exclude unknown creation dates.

A real task edit/add/remove, or a new task file, writes format 2. Replacement
preserves exact original bytes in a unique `todo.txt.backup-<ID>` through the
existing hash/lease/atomic writer. IDs, completion and descriptions are retained.
Invalid metadata and external conflicts fail visibly without overwriting intent.

**Older plugins cannot read format 2.** Close Scribe and preserve the complete
current task file and backups before any deliberate downgrade. An older backup
is not an automatic merge or a replacement for newer tasks.

## Verification and limits

813 core checks and a warnings-as-errors plugin build passed, plus 34 synthetic
non-showing task-view checks. Cases include raw-byte legacy preservation,
metadata/escaping round trips, conflicts, scoped/combined filters, stable sorts,
hidden control handles and actual priority-dropdown edits, completion edits,
date-bound toggles, 1060/740-pixel layouts, no-save queries and recovery.

The updated copied-native suite compiled with warnings as errors but was not
executed. No FCS executable, native model, visible forms, native TODO window or
live mod was opened. This is not physical beta 24 acceptance or independently
rerun native selection/type integration. The beta 23 checklist and beta 21
owner report remain separate; the earlier saved-mod discrepancy stays open.

## Installation and compatibility

Requires Windows, .NET Framework 4.8, installed FCS Extended and the inspected
Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Back up mod/native annotations, Scribe notes/tasks/settings, complete private
tracking sets and draft workspaces. Close FCS, verify the ZIP against its matching
`.sha256` asset and install its `FCS-Scribe` folder normally. Never replace upstream
binaries. `release.json` binds the package to its exact source and guarded FCS
executable. Publishing/building this release does not install it.

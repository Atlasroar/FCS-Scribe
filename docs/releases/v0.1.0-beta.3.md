# FCS-Scribe v0.1.0-beta.3

Experimental beta prerelease focused on a cleaner UI and a stabilization-first
work plan. The full interactive FCS Extended acceptance gate remains open;
use disposable mod copies first.

## Changes since v0.1.0-beta.2

- Replace the ten-button row with **Core**, **Workshop** and **Draft** dropdowns.
  Core contains Start tracking, Review changes, Compile journal and Export AI
  packet. Workshop contains Export Workshop info and Archive preview image.
  Draft contains Import draft and Paste draft.
- Keep **Apply approved notes** and **Settings** as separate top-level actions
  inside Scribe; the menus do not merge into the parent FCS window.
- Preserve bottom hover/keyboard-selection explanations and the separate
  operation status. Narrow windows retain actions through an overflow menu.
- Preserve the serialized operation gate and explicit notes approval.
  Automatic work defers while menus are open rather than interrupting selection.
- Add sixteen stabilization items with acceptance checklists to the Copilot
  plan. Address these one at a time before OCS, new documentation formats or
  direct AI-provider integration.
- Simplify the README to a feature/wiki index, retain authoritative upstream
  references and disclose AI assistance. Consolidate detailed instructions in
  the wiki, including a new building-and-releases guide.
- Correct the draft guidance: valid citations are checked, but validation does
  not yet require every exported change to be cited.

**This is a UI/documentation release, not completion of the stabilization
backlog.** S01-S16 remain open. No tracking/AI schema, mod-writing or
notes-approval behavior is changed.

## Installation and upgrade

Requirements: Windows, .NET Framework 4.8, installed FCS Extended and the
inspected Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Close FCS, extract the archive and copy its `FCS-Scribe` folder into
`<Kenshi>\mods\FCS-Scribe`, replacing the older plugin files if upgrading.
Launch FCS Extended and enable FCS-Scribe. Back up your mod projects and FCS
notes files before trying this experimental build. Building or downloading
the release does not install it or modify your game.

Existing beta 2 tracking projects keep the same format. Keep each baseline JSON
with its adjacent `.json.scribe` storage, marker, main journal and uncompiled
sessions. Draft text/export associations still do not survive window restart.

## Important limitations

- Draft validation can accept omitted change evidence; review coverage and
  factual correctness yourself before approving notes.
- AI export uses pending evidence or the latest compatible recorded batch,
  not the full accumulated session history. Context-only changes can make the
  previous gameplay batch ineligible for export.
- Workshop/cache/preview failures can still block ordinary model capture.
- Tracking is not a `.mod` backup or automatic lost-edit recovery. Full
  baselines/dependency data and session logs may be private: do not send them
  to AI or include them in Workshop uploads.
- Extraction is partial and interval-based, not an every-event log. Large
  captures and long unpruned histories remain UI-latency/32-bit memory risks.
- Notes are editor-side per-record sidecars, not `.mod` content or Workshop
  release notes. Multi-record application is not transactional and never
  saves automatically.
- Full FCS Extended loader/menu/dialog acceptance and broader mod-stack
  coverage remain pending. Other FCS builds and GOG are not validated.
- See the [stabilization plan](https://github.com/Atlasroar/FCS-Scribe/blob/main/docs/plan.md#stabilization-gate-before-further-feature-work)
  for initialization, settings, compilation-deadline, overwrite, storage and
  portability concerns. OCS, Markdown/wiki-ready gameplay exports and direct
  AI-provider connections remain planned, not shipped.

## Validation and source

Recorded checks: **138 core**, **136 disposable vanilla FCS** and **135
representative-mod FCS** checks passed. The representative mod has no instances;
that mutation was explicitly skipped there and covered by vanilla. Menu checks
include exact grouping, hover/keyboard help, narrow-window overflow, serialized
dispatch and deferred automatic work while menus are open.

The ZIP includes the plugin, manifest, README, documentation, GPL-3.0 license
and `release.json` with the exact source commit. No Kenshi, FCS or upstream
FCS Extended binaries are bundled. Verify the ZIP against its separate
`.sha256` asset; the matching Git tag/source archives supply corresponding
source. Automated disposable-copy checks do not replace interactive acceptance.

# FCS-Scribe v0.1.0-beta.6

Experimental beta addressing **S03: optional Workshop failures stopping
ordinary gameplay tracking**.

## Changes since v0.1.0-beta.5

- Isolate known cache/preview file, XML and image-decode failures from gameplay
  capture. Retain active header fields and FCS-derived dependency/reference
  lists. Invalid preview data no longer discards readable metadata; cache
  failure no longer discards an independently readable preview.
- Report `CaptureStatus: "partial"` and structured component/code/message
  `Issues`, snapshot/Workshop warnings, bottom status, AI guidance and approval
  notices. Unavailable previews have an explicit `UnavailableReason`.
  Expected missing files retain their existing missing/unknown meanings.
- During a matching Workshop upload/connected refresh, skip unstable staged
  values and preview reads while gameplay capture continues. Offline disabled
  controls alone do not mean a refresh is active.
- Preserve meaningful stale-state checks: known field changes, availability
  loss/recovery and changed reasons affect fingerprints. Repairing optional
  data is recorded as context without fabricating gameplay changes.
- Keep archiving strict: require a readable supported image, retain original
  bytes and reject upload/refresh starting during archive selection.
  Workshop-only export/archive errors still show an error but do not pause
  gameplay automation or clear an earlier pause.
- Retain failure/pause behavior for ordinary model/journal errors. Unexpected
  reflection/contract failures and fatal resource errors are not suppressed.
- Update the Copilot plan/wiki and beta 6 metadata. S04-S16 remain open.

## Installation and compatibility

Requirements: Windows, .NET Framework 4.8, installed FCS Extended and the
inspected Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Close FCS, extract the archive and copy its `FCS-Scribe` folder into
`<Kenshi>\mods\FCS-Scribe`, replacing older plugin files when upgrading.
Launch FCS Extended and enable FCS-Scribe. Back up your mod projects and FCS
notes files first. Building/downloading does not install or change your game.

Packet/tracking/session schemas and note formatting are unchanged. Availability
fields are optional and omitted when no component failure exists. Older packet
serialization remains intact; new partial captures intentionally have distinct
context fingerprints. Resume the original tracking JSON and `.scribe` folder,
not an AI handoff.

## Remaining boundaries

- Unavailable payload bytes cannot be validated. Different unreadable content
  with the same reported state/reason may have the same fingerprint. Partial
  capture is not confirmation of those fields.
- Workshop information remains local/staged/cached, not a fresh Steam listing.
  Scribe does not invoke Save, Refresh, Upload, download or source repair.
- Known optional failures no longer stop gameplay tracking, but unsupported
  model/adapter contracts, ordinary journal errors and fatal resource failures
  remain explicit failures.
- Tracking is not a mod backup. Draft/export associations remain window-local;
  transactional notes, storage safety, performance/portability and S04-S16 work
  remain unresolved.
- Full interactive FCS Extended acceptance, real asynchronous Steam operations
  and broader stacks/builds remain unverified. Disposable form/method checks do
  not close that gate.

## Validation and source

Recorded checks: **215 core**, **235 disposable vanilla FCS** and **234
representative-mod FCS** checks passed. The representative mod has no instances;
that mutation was explicitly skipped there and covered by vanilla.
Coverage includes missing, malformed, mismatched and locked caches; malformed,
unsupported, oversized and locked previews; simultaneous failures; busy
upload/refresh; known-field preservation; stable repeated capture; durable
gameplay recording; replay/range export; actual timer-based recording and
availability recovery; stale drafts; independent strict archiving and action
pause policies.

A separate cross-version check generated real compiled/uncompiled Workshop
history using the released beta 5 binary, then verified beta 6 replay/export
with exact original packet serialization and unchanged tracking-file hashes.

The ZIP contains the plugin, manifest, README, documentation, GPL-3.0 license
and `release.json` identifying the exact source commit. No Kenshi, FCS or
upstream FCS Extended binaries are bundled. Verify the ZIP against its
`.sha256` asset; the matching Git tag/source archives supply corresponding source.

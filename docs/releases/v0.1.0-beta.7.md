# FCS-Scribe v0.1.0-beta.7

Experimental beta addressing **S04: editable drafts and their original AI
packet associations being lost on close or replacement**.

## Changes since v0.1.0-beta.6

- Add **Draft > Save workspace** and **Open workspace**. One versioned JSON
  retains exact editable text, including unfinished/invalid JSON, and its
  original schema-1/2/3 AI packet. Original recording-range evidence is retained,
  not rebuilt or rebound to today's history.
- Protect unsaved text and new export associations before close, Start/resume,
  new AI export, Import, Paste and Open with Yes (save), No (discard), or Cancel.
  Cancellation and failed storage/validation retain the current work.
- Mark unsaved work in the window title. Background saves retain a snapshot;
  later edits remain visibly unsaved. Revision guards prevent background
  Open/Start from clearing newer edits. Close during an operation is cancelled
  and can be retried after completion.
- Validate restored bundle integrity and report stale, mismatched, unfinished
  or already-applied responses against original evidence and current state.
  Apply always revalidates and requires fresh explicit approval.
- Preserve unassociated text as an explicitly text-only workspace, never as
  fabricated evidence. Missing/corrupt associated packets fail loading.
- Reuse atomic flushed JSON writes, observed-file conflict checks and previous
  workspace `.bak` backups. Workspace Save refuses unrelated existing JSON;
  Open rechecks source bytes after replacement confirmation.
- Update the README's feature links, wiki, stabilization plan and beta metadata.
  S05-S16 remain open; no unrelated feature expansion is included.

## Installation and compatibility

Requirements: Windows, .NET Framework 4.8, installed FCS Extended and the
inspected Steam FCS 2.14.2 executable with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Close FCS, extract the archive and copy its `FCS-Scribe` folder into
`<Kenshi>\mods\FCS-Scribe`, replacing older plugin files when upgrading.
Launch FCS Extended and enable FCS-Scribe. Back up your mod projects and FCS
notes files first. Building/downloading does not install or change your game.

Packet/tracking/session schemas and note formatting are unchanged. Workspaces
use their own `FCS-Scribe draft workspace` format, schema 1; they are not AI
response JSONs or tracking baselines. Open restores text/packet association
without requiring the original export file or an active tracking session.
Resume tracking separately using the original baseline and `.scribe` folder.

## Remaining boundaries

- This is explicit Save/Open, not autosave or crash recovery. Forced termination
  can still lose later unsaved edits. Parent-editor close may need to be retried
  after a workspace decision or in-flight operation.
- A saved workspace is not approval, a mod backup, tracking resume or a global
  record of documented evidence. Hash checks are consistency checks, not
  signatures. Private evidence/prose must be inspected before sharing.
- Stale prose remains recoverable for inspection, not automatically reassociated
  with a new export. Normal FCS Save can change captured headers and stale work.
  Notes remain nontransactional editor-side annotations; ordinary approval,
  exactly-once evidence coverage and safe retry checks still apply.
- Full interactive FCS Extended acceptance, native file/overwrite/approval
  dialogs, broad storage/portability/performance hardening and S05-S16 remain.

## Validation and source

Recorded checks: **235 core**, **260 disposable vanilla FCS** and **259
representative-mod FCS** checks passed. The representative mod has no instances;
that mutation was explicitly skipped there and covered by vanilla.
New coverage includes original/qualified evidence preservation, exact text,
unfinished/mismatched/stale responses, missing/corrupt packets, new-window
restore, dirty-state changes, cancelled replacement/closing, late background
edits, source/target conflicts and no implicit application.
Decision-boundary tests do not replace full native-dialog acceptance.

The ZIP contains the plugin, manifest, README, documentation, GPL-3.0 license
and `release.json` identifying the exact source commit. No Kenshi, FCS or
upstream FCS Extended binaries are bundled. Verify the ZIP against its
`.sha256` asset; the matching Git tag/source archives supply corresponding source.

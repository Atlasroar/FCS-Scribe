# FCS-Scribe v0.1.0

First normal, non-prerelease package under Semantic Versioning 2.0.0.
Major zero remains initial development: this does not declare a stable 1.0 API,
broader editor support or new physical acceptance.

## Changes from beta 25

- Include the project's `FCS-Scribe.mod` carrier, `_FCS-Scribe.info` Workshop
  metadata and `_FCS-Scribe.img` preview, imported exactly from the owner's
  deployment. Existing Workshop identity and original bytes are preserved.
- Rebuild the plugin from current tagged source. The inspected deployment was
  beta 23; its older DLL, release manifest and documentation are not imported.
- Exclude deployment-specific settings/locks and all private notes, tasks,
  tracking, workspaces and backups.
- Refresh the current-release wiki and retain the 32-item checklist with all
  checks Not run. The carrier's older publishing text is not the current
  authoritative feature/support guide.
- Document the versioned compatibility surface and major-zero SemVer policy.
  Packaging now refuses to overwrite an existing version's ZIP/checksum.

Includes all beta 25 features: resumable recording, manual AI handoff,
reviewed native annotations, Markdown/history browsing, opt-in notes/task
management and guided compiled-original archive/restore. No new gameplay
tracking or AI/runtime integration is introduced. Every historical recording
remains retained; archives are not complete backups.

## Compatibility and acceptance

892 core checks, a warnings-as-errors build, 20 non-showing history checks
and 34 non-showing task checks passed on the release source. Imported asset
hashes and preview decoding were verified; no native/visible acceptance is
implied by those checks.

Windows, .NET Framework 4.8 and FCS Extended are required. Only the inspected
Steam FCS 2.14.2 executable is supported, with SHA-256:

```text
3688c4d8421d51c2d30c2ff0338874779d91eff150c6a02bf415bc1cdd9c7796
```

Existing tracking/AI/draft/task schemas remain unchanged. Format-2 tasks still
cannot be read by older plugins. Normal release status does not resolve the
earlier saved-mod discrepancy or replace scoped historical evidence with
physical acceptance. No live installation or native/visible FCS test is
performed as part of publication.

Close FCS, preserve complete private backups and user settings, verify the
ZIP against its matching checksum, then install the packaged `FCS-Scribe`
folder. Do not replace upstream binaries or treat Workshop metadata as an
automatic upload. `release.json` binds the package to exact source.
